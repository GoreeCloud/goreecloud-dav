# GoreeCloud DAV Branding

## Canonical identity

- Official full name: **GoreeCloud DAV**
- Approved short name: **DAV**
- Master brand: **GoreeCloud**
- Brand relationship: **prefixed GoreeCloud family service**
- Repository: `goreecloud-dav`
- Suite membership: no; this is an infrastructure/interoperability service.

## Usage

Use **GoreeCloud DAV** on first meaningful reference when the service appears outside an already clear GoreeCloud context.

Use **DAV** as a short label inside clearly branded GoreeCloud administration, engineering, or service contexts where it is unambiguous.

## Technical identifiers

Technical identifiers may use lowercase `goreecloud-dav` where the relevant system convention requires it.

The current Go module is:

```text
github.com/GoreeCloud/goreecloud-dav
```

## Radicale relationship

Radicale is not part of the product identity.

Do not describe the project as:

- GoreeCloud Radicale;
- a Radicale edition;
- a rebranded Radicale;
- Radicale by GoreeCloud.

The product is an original GoreeCloud DAV implementation using public DAV standards as interoperability targets.

## Visual identity

The current repository is a headless service and does not establish a new standalone visual mark.

If a user-facing administrative interface or canonical icon is introduced later, it must follow the applicable GoreeCloud official visual-identity and Glaze UI standards before being represented as final.
